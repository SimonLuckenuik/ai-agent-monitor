# Decision records

A decision record is a dated finding or choice, with the evidence that produced it.
Records are never edited after the fact; a later record supersedes an earlier one. Write
one when a choice changes the design, a budget or a release, and link it from the spec
it belongs to ([specs](../../specs/README.md)).
