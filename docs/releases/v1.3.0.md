SmartClock-OSS 1.3.0 lets you **hide the time on photos**, so it no longer covers Home Assistant dashboards, and **says why the clock cannot join your WiFi** instead of only showing the setup screen again.

## Download

**`SDPro_SmartClockOSS_v1.3.0.bin`**: one file for both the stock update page and our own. Keep the file name: the stock page only accepts names starting with `SDP`. It contains no WiFi details.

SHA-256: see `SHA256SUMS.txt` attached to the release.

## Upgrading

- **From 1.2.0 or 0.1.2:** install it from the **Firmware update** card. Your settings and photos stay.
- **From 0.1.1 or earlier:** the settings page and setup network now ask for the clock's password. On the sign-in page, press **Show the password on the clock** (see the [0.1.2 notes](https://github.com/michaeldale/smartclock-oss/releases/tag/v0.1.2)).

## New

- **Show the time on photos** ([#1](https://github.com/michaeldale/smartclock-oss/issues/1)). A switch on the Photos card, on by default. Turn it off when [geekmagic-hacs](https://github.com/adrienbrault/geekmagic-hacs) pushes dashboards, so the time does not cover them. Scripts can set it with `/api/set?key=photoclock&value=0` while signed in.
- **Why WiFi will not connect** ([#2](https://github.com/michaeldale/smartclock-oss/issues/2)). When a 30 s attempt to join the saved network fails, the setup screen and the settings page show the reason: network not found, wrong password, connection refused, or no answer. The clock tries again every 5 minutes, so give it a few minutes after saving. It joins 2.4 GHz networks only.

## Known limitations

- Both changes have been built and tested on the PC but not yet on a clock. Please report what you find.
- MQTT has still not been tested against a real broker and Home Assistant.
